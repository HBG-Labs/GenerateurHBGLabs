## ARCHITECTURE

The dependency direction is `CreativePlan -> VisualDirectionPlan -> AssetIntent -> ProceduralAssetPlan -> VisualPlan -> MotionSpec -> P1 -> renderer`. Procedural Asset Core is renderer-, React-, Remotion-, provider-, network-, and Blender-independent. P1 receives only validated primitives and has no knowledge of asset-family concepts such as cards, dashboards, or device frames.

## PROCEDURAL ASSET CONTRACT

`ProceduralAssetPlan 0.1.0` is strict, versioned, canonical, bounded, and data-only. It defines stable asset/component identities, semantic roles, hierarchy, materials, geometry intent, focusability, depth, affordances, complexity, cost class, provenance, and deterministic seeds. It accepts no JSX, CSS, JavaScript, raw HTML, arbitrary SVG, URL, path, shader, or command.

## KNOWN LIMITATIONS

- Procedural assets only; no generated images, photography, user-image understanding, or subject cutout.
- No true 3D, Blender, mesh, lighting simulation, or GPU requirement.
- No audio, TTS, music, SFX, Visual Critic, provider Visual Director, or media provider.

## TECHNICAL DEBT

- Several less-specialized families share a generic deterministic component resolver; family-specific refinement can improve structure without widening the contract.
- Nested renderer/DOM complexity is not yet reported independently from semantic component count.
- Optional Science/Editorial reference compositions need budget-aware adaptation within existing P1 limits.
- Local Webpack cache corruption warning should be eliminated operationally; it does not affect clean CI.
- Material recipes remain renderer approximations and need further cross-platform visual-golden breadth.

## DEVIATIONS

- Only Product/App is produced as a final P3.3.5 film. Science and Editorial were optional after the mandated Product priority and were stopped at certified asset/golden coverage because their current full fixtures exceed P1 motion budgets.
- `GRADIENT_LAYERED` is a deterministic layered treatment, not an arbitrary continuous shader.
- Advanced product renders and image slots remain unsupported rather than being replaced silently by poor placeholders.
- The certification renderer now regenerates the P3.3A Product baseline instead of copying an ignored pre-existing local artifact; this strengthens clean-checkout reproducibility.
