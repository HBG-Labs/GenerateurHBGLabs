# Benchmark roadmap impact

## Decision

**P3.3 readiness: READY.**

The original five-anchor evidence was too narrow for this decision. After six
research waves, 35 complementary public case studies, 21 creators/studios, 16
normalized cross-category families and 11 TechniqueCompositions, no single
missing engine primitive is shown to constrain almost every premium result.

The dominant repeated gaps are instead:

- asset/material richness and mixed-media binding;
- motion-identity and sequence-strategy selection;
- domain compositions for UI/product/data;
- a bounded set of already-known simplified resolvers.

P3.2 already provides enough deterministic, closed vocabulary for a constrained
Visual Director to choose composition, motif, pacing, restraint, continuity and
supported technique combinations. `READY` does not mean the asset ceiling or
showreel gap is solved.

## Before P3.3

No engine extension is mandatory before P3.3. The following remain authorized
research/backlog candidates only:

1. complete the existing type/mask/portal simplified family rather than adding
   unrelated effects;
2. define a minimal deterministic Procedural Asset Grammar for layered vector
   illustration and generic UI/device/data surfaces;
3. retain local timecoded analysis as the gate for any general compositor,
   general path-follow or substantial P1 change.

General compositor, path-follow and arbitrary morph remain unsupported and must
not be offered to a P3.3 model.

## P3.3

The Visual Director should choose only supported registry IDs and
parameters. It should own sequence strategy, layouts, focus, motifs, restraint,
pacing/intensity, asset roles, phrases, bridges, camera, and depth. Structured
output and local VisualPreflight remain mandatory; the model must not invent
animation code or unsupported capabilities.

## P3.4–P3.7

- P3.4: image understanding, subject/layer/depth extraction;
- P3.5: Image → Motion using approved semantic layers;
- P3.6: Image + Instructions → Video;
- P3.7: rendered-frame Visual Critic and targeted visual repair.

Poster deconstruction and subject isolation naturally depend on P3.4 unless
layers are authored manually. Asset generation remains behind an approved
AssetIntent/Asset Director boundary.

## Future 3D and audio

True mesh/material/light/camera/particle/physics gaps belong to a controlled
`3DScenePlan → allowlisted adapter → renderer → P1 compositing` path. They do not
justify Blender in P3.2.x. Sound-motion coupling belongs to a future AudioPlan and
Sound Director using existing deterministic sync anchors.

## Saturation policy

Stop adding references when new samples only repeat already confirmed families.
Prefer missing categories: typography-only, product visualization, data motion,
character, architectural, fashion/editorial, cinematic titles, UI walkthrough,
infographic, social ad, broadcast, and logo motion.

## Priority map after expansion

### Priority A

- P3.3 sequence strategy, art-direction selection and motion-identity recipes;
- Procedural Asset Grammar/material roles as a parallel or immediate follow-up;
- UI/product TechniqueCompositions using only current capabilities;
- bounded completion of type/mask/portal simplifications when separately
  authorized.

### Priority B

- data/information composition library;
- poster semantic layer contract;
- deterministic texture/matte proof;
- timecoded analysis for compositor/path-follow decisions;
- low-coverage reference categories.

### Priority C

- arbitrary morph, complex character rigging and specialized broadcast systems;
- true 3D/Blender/cloud-GPU pipeline;
- audio coupling and Visual Critic.
